INSTRUCTIONS for setup and use 
1. Install Python 3.12 (or newer).

2. Install MacTeX:
https://www.tug.org/mactex/

3. Open a terminal in this folder.

4. Install the required Python packages:

pip install -r requirements.txt

5. Run the interface:

streamlit run interface.py

6. When inputing lexical items: 
    - use $\bot$ for the bottom of the tree
    - avoid things like $\#$ or $\pi$ and use instead something like Num and Person 
    - remove all whitespace and newline characters after building the LaTeX tree so that it is all on one line
